# Beginner 트랙

Kubernetes를 처음 접하는 학습자가 로컬 클러스터에서 기본 워크로드를 배포하고 운영하는 과정을 익히는 트랙입니다.

## 트랙 정보

- 대상: 컨테이너의 기본 개념을 알고 있는 Kubernetes 입문자
- 실습 환경: Windows 11의 Git Bash 또는 Linux/macOS Bash, Docker, kubectl, kind
- 권장 진도: 주 1~2강, 강의당 90~120분
- 상세 과정: [CURRICULUM.md](CURRICULUM.md)

## 강의 목록

| 강의 | 주제 | 상태 |
|---:|---|---|
| 1강 | [첫 Pod 실행하기](lessons/01-first-pod/README.md) | 제공 |
| 2강 | Deployment와 자가 복구 | 예정 |
| 3강 | 롤링 업데이트와 롤백 | 예정 |
| 4강 | Service와 클러스터 네트워크 | 예정 |
| 5강 | Ingress와 로컬 라우팅 | 예정 |
| 6~12강 | 설정, 안정성, 데이터, 운영, Helm, 종합 실습 | 예정 |

강의는 순서대로 진행하는 것을 권장합니다. 특정 강의만 다시 실습할 때는 해당 강의 디렉터리의 `README.md`에서 준비물과 정리 절차를 먼저 확인합니다.
